## 1. 自洽方程的建立

**已知（v2.2）**：几何反解势 `α·M̃ − β·ℛ̃ = Θ·g̃` ⇒ `∂_A∂_B V = κ·g̃_AB`

规律空间取常曲率球面 S^N（N = 11 = 1+4+6）：

```
ℛ̃_AB = (N-1)/R² · g̃_AB ,     Θ = −(N-1)(N-2)/(2R²)
```

取归一化 α = 1（α 可被吸收进 κ 的定义），得

```
κ(R) = 2[ (Θ−1) + β(N−1)/R² ] = 2[ A/R² − 1 ] ,      A ≡ (N−1)[ β − (N−2)/2 ]      …(1)
```

**约束自洽**：V(L) = ½κ|L|² 的谐振子基态宽度 σ² = ℏ/√(Mκ)；球面支撑尺度与之匹配 R² = c²N·σ²，令

```
B ≡ c²Nℏ/√M ,     R² = B/√κ     ⇒     κ = B²/R⁴                                    …(2)
```

**联立 (1)(2)**，令 ρ ≡ R²：

```
ρ² − Aρ + B²/2 = 0        ⇒        ρ = [ A ± √(A² − 2B²) ] / 2                     …(3)
存在条件： A² ≥ 2B²  且  ρ > 0
```

**反解式**（给定参考半径 R\*）：`A* = ρ* + B²/(2ρ*)`，`β* = A*/(N−1) + (N−2)/2`
