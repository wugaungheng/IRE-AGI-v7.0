## 摘要

本文提出并系统整理「武光衡宇宙统一方程」（WGE）框架，并给出其**可复验的硬核**：一组关于该框架内两类核心约束不可同时满足的**互斥定理**、一条**复合转换闭合阈值定理**（充要条件级），以及由此导出的**判决性预言**与**外部锚量纲门**判定。

框架本体为单一对数行列式作用量

```
𝓛 = −Tr ln(𝕀 + 𝕏) ,   𝕏 ≡ (αM̃ − βℛ̃) g̃⁻¹
```

定义在 N = 11 = 1 + 4 + 6 的构件空间上，其可判定性压缩为一条区间判据 β ∈ (β_B(α), β_A(α))。

在此框架的谱维数桥接口径下（前提 λ ≡ const），本文证明三条互锁结论：

1. **恒等式（NG-1）**：(1 + ε_κ)·span_c ≡ R 对桥接族内一切 γ 严格成立，其中 R = 102.02067183462532 为行星半径比（水星 0.387 AU 至冥王星 39.482 AU）。
2. **紧界（NG-2 / NG-6）**：span_c ≥ max{1, R(1−ε_κ)/(1+ε_κ)}，且在全部 ε ∈ (0,1) 上由「比例核截断」构型精确取到；由此现行判据 FC-2（span ≤ 2 且 ε ≤ 0.96）**自身不相容**。
3. **闭合阈值定理**：对任意容差 tol，存在同时满足 κ-恒等与 c-常数的解，**当且仅当** tol ≥ tol* = (r_max − r_min)/(r_max + r_min) = 0.9805864205272267；其对偶推论给出 **域收缩**：在 tol = 1e-16 的严格口径下，闭合要求半径域的相对宽度 ≤ 2.220446049250313e-16（域收缩为单点），而实际 R = 102.02067183462532，**相差 102.020672 倍**。

放宽前提 λ ≡ const 后（λ 化为场变量 λ(r)），条件可被**精确**满足（状态 B′：ε = 0、span = 1），但代价不可消除：λ 退出常数集、绝对标度不可内生（解流形 1 维）、一切仅依赖 (ε, span) 的判据被架空。据此，本文把 no-go 从「λ 常数族」升级为含 λ 跑动的普适形式（NG-7），并证明项目内观测量按规范权重 w = p_λ + p_c 分类（342 项普查：48 项 w = 0 者判别力结构性为 0；294 项 w ≠ 0 者无法在项目内赋定值）。

对「外部带量纲锚」通道，本文给出**量纲门审计**：框架内的 λ（长度，1e20 m 量级）与星系反演式中的 λ（无量纲，恒 ≈ 1）量纲不同一；唯一量纲自洽的 λ↔质量桥（康普顿桥 m_eff = ħ/(cλ)）在数值上不可达（相差 32.41 个数量级）。因此「合格外部锚 = 0」**不是数据收集不足，而是表述层缺口**。

## 1. 引言：方程的定位

「武光衡宇宙统一方程」由两部分构成，二者在数学上各自独立、经一处单向只读接口衔接：

- **WGE 侧（几何—涨落侧）**：单一对数行列式作用量及其五层架构、区间判据，构成可算、可复现的闭环（第 1–4 层）；
- **信息方程侧（信息—熵侧）**：信息场演化与意识熵留痕，其概念母版为论文《信息与宇宙》的公设体系。

两套体系的确证交集**只有一处**：意识熵 S_c 的单向只读耦合（工程侧红线禁止自喂闭环）。除此之外，两条线索在数学上互相独立，参数不可互换。

本文的核心贡献不在于宣称「已统一」，而在于给出该框架**可被独立检验的硬核**：

1. 框架内两类核心约束（κ-恒等与 c-常数）在 λ 常数前提下**经证明不可同时满足**；
2. 该不可能性的**充要阈值**可精确写出并被数值锁定；
3. 放宽前提后的**逃逸解存在但退化**，且退化不可消除（规范对称性的必然推论）；
4. 由此导出**一次测量即可判决两条路线**的实验通道。

## 3. 核心互锁结构：κ-恒等与 c-跨幅的互斥

### 3.1 恒等式（NG-1，解析证明 + 数值复核）

对 γ-桥接族（λ 常数）：c_γ(r) = (λ/r)·(r/r₀)^γ，ε_κ(γ) = R^γ − 1，span_c(γ) = R^(1−γ)，于是

```
(1 + ε_κ(γ)) · span_c(γ) ≡ R ,   ∀γ
```

**推论 NG-1′（靶值互斥）**：span_c ≤ 1.001 ⟺ ε_κ ≥ R/1.001 − 1 = 100.9187530815。

### 3.2 紧界与可达性（NG-2 / NG-6，λ 常数前提）

对任意桥接函数 c(r)（λ 常数）：

```
span_c ≥ max{ 1 , R(1 − ε_κ)/(1 + ε_κ) }
```

推论：span ≤ 1.001 ⟹ ε ≥ 0.9805671956；span ≤ 2 ⟹ ε ≥ 0.9615461。

该界**可达**，等号构型为**比例核截断**：

```
u(x) = min( (1 − ε)·x , 1 + ε ) ,  x = r/r_min
```

**独立复算**（R42）：18 点 ε 网格（含 ε ≥ 0.980567 区间）等号全部成立，**0 违例**；受约束族扫描 9 族 19045 点可行点 = **0**。

**数值复核**（R37/R42）：d_s ∈ [2,3] 的 200001 点扫描中，同时满足 `span ≤ 1.001` 与 `ε ≤ tol_eff = 6.817105e-10` 的点数 = **0**（其中 span ≤ 1.001 的 44 个点，最小 ε = 100.919272）。

> **前提警示（勘误 R50-4）**：NG-2 / NG-6 的「形式无关」仅对 **u 的函数形式**成立，且以 **P1 为前提**。λ 跑动解（λ ∝ r）给出 ε = 0、span = 1，低于右端 R = 102.020672，**违反倍数 102.0207**，构成 P1 的反例。

### 3.3 判据不可满足（NG-5）

判据 FC-2（存在独立口径使 span_c ≤ 2 且 ε_κ ≤ 0.96）在 P1 下**不可满足**：由 NG-2，span ≤ 2 蕴含 ε ≥ (R−2)/(R+2) = 0.9615461 > 0.96，与自带上界矛盾。

⇒ **现行判据口径「保 κ 恒等（ε ≤ 1e-10 量级）且压平 c 跨幅（span ≤ 1.001）」在 P1 下数学不可满足。**

### 3.4 固定线退化（NG-3）

映射 d_s ↦ (span_c, ε_κ) ↦ d_s 在 γ-桥接族上是**恒等映射**，故任意 d_s 均为自洽不动点（20 段网格最大恒等残差 < 1e-12）。**单独依靠族内规则无法内生唯一确定 d_s。**

### 3.5 信息几何—谱几何等价（NG-4）

在 γ-桥接族内，信息几何口径 span_IG = R^√G（G = (∂ln c/∂ln r)²）与谱几何口径 span_S1 = R^(3−d_s) **逐点相等**（最大偏差 0.0，R39）；λ 跑动后该等价仅在逐 r 局域意义下保留。属**代数重参数化**，不构成独立物理验证。

## 4. 复合转换闭合阈值定理（充要条件级）

### 4.1 定理

设指认读数 c(r) 与桥接比值 u(r) := c(r)·r/λ，两条约束为

- **(A) κ 恒等**：max_r |u(r) − 1| ≤ tol；
- **(B) c 为常数**：c(r) = const。

记 R := r_max/r_min，则：

> **对任意容差 tol，存在同时满足 (A)(B) 的 c，当且仅当 tol ≥ tol\* = (r_max − r_min)/(r_max + r_min)。**

**证明**：若 c ≡ k，则 (A) 等价于对所有 r：1 − tol ≤ k·r/λ ≤ 1 + tol。取端点得 k·r_min/λ ≥ 1 − tol 且 k·r_max/λ ≤ 1 + tol ⟺ (1 − tol)/r_min ≤ (1 + tol)/r_max ⟺ tol ≥ (r_max − r_min)/(r_max + r_min) = tol*。∎

**最优可达残差（对偶）**：常数 c 下的最小可能残差恰为 tol*，由 k* = 2λ/(r_min + r_max) 取到。

**推论（双向下界对偶）**：`span_c = 1 ⟹ ε ≥ (R−1)/(R+1)`；`ε = 0 ⟹ span ≥ R`。二者与既有闭式互证，说明**不存在任何函数形状**可同时满足两约束。

### 4.2 数值验证

`λ = LAMBDA_GRAV_DEFAULT`，网格 r ∈ [0.387, 39.482] AU（401 点对数），POCS 交替投影 4000 次：

| tol | 理论可行 | 收敛后 ε_κ |
|---|---|---|
| 1e-16 | 否 | 21.0631 |
| 0.1 | 否 | 19.7063 |
| 0.9 | 否 | 3.96213 |
| tol* − 1e-9 | 否 | 0.980586 |
| **tol\* = 0.9805864205272267** | **是** | 0.980586 |
| 0.99 | 是 | 0.99 |

实测阈值与闭式解在 1e-15 内一致，**扫描在阈值两侧精确翻转**。

### 4.3 域收缩推论（R59，新证明）

由阈值定理反解：`tol ≥ (R−1)/(R+1)` 是拟合恒等的**充要条件**。故在 tol = 1e-16 下要求恒等，必须

```
R ≤ (1 + tol)/(1 − tol) = 1 + 2.220446049250313e-16
实际 R = 102.02067183462532   （相差 102.020672 倍）
```

⇒ 在严格恒等口径下，任何保留半径依赖的候选公式都**不可能**同时满足 κ-恒等与 c-常数。

另经独立复核：前沿闭式 s_min = R(1−tol)/(1+tol) 在 10 档 tol × {9 点, 401 点} × LP 独立求解下成立，相对偏差 ≤ 1.4e-16（**形态无关**）。

### 4.4 三支穷尽

| 分支 | 内容 | 实跑判定 |
|---|---|---|
| P-2A | 弃 c 常数（读法 B：c(r) = λ/r 随动） | 候选口径层通过；目标级仍不通过 |
| P-2B | 弃 κ 恒等（读法 A：冻结 c） | 未成立 |
| P-4 | 弃 r 依赖（域单点化） | 目标级不通过 |

⇒ 闭合只能经「放弃 r 依赖」或「放弃 κ 恒等」之一实现，**二者皆非无条件打通**。

### 5.3 含 λ 跑动的普适 no-go（NG-7）

- **NG-7a**：设 λ = λ(ρ) 单值、ρ(r) 单调非常数，则满足 (E-κ ∧ E-c) 的解必为 λ(ρ) = c0·r(ρ)，λ 必非常数，且 λ 跨幅恒等于 R。
- **NG-7b**：条件集在 (λ, c) → (kλ, kc) 下严格不变（最大偏离 9.799e-17）⟹ 解流形 ≥ 1 维，绝对标度不可内生。
- **NG-7c**：在 λ 跑动解上 ε = 0、span = 1 恒成立 ⟹ 任何仅依赖 (ε, span) 的判据自动满足、鉴别力归零。
- **NG-7d**：P1 下下界严格成立，而 λ 跑动解为其反例 ⟹ 一次 (ε, span) 测量即可判决两条路线（实验判决通道）。

## 6. 规范权重代数与不可闭合的结构性归因（NG-8 / NG-9）

### 6.1 规范权重代数（NG-8）

规范作用 (λ, c) → (kλ, kc) 保持全部既有判据所依赖的比值结构不变。量 X 的规范权重 w 由其在 {λ, r, c} 上的幂次给出 w = p_λ + p_c。对 {λ, r, c} 上幂次 ∈ [−3,3]³ 的全部 **342**（= 7³ − 1）个非平凡单项式逐项验算：

| 类别 | 项数 | 规范变动上界 | 判定 |
|---|---|---|---|
| 规范不变项（w = 0） | **48** | 6.661e-16 | 判别力**结构性为 0** |
| 规范协变项（w ≠ 0） | **294** | 按 k^w 变化（预测误差 0） | 定值**必须**由外部带量纲锚给出 |

> **NG-8**：项目内可及的一切观测量与判据（含 ε_κ、span_c、R、S_c、tol_eff）均由 {λ, r, c} 幂律生成。w = 0 者对 λ 绝对标度**结构性无判别力**；w ≠ 0 者无法在项目内被赋定值。故「独立观测量库为空」是**规范对称性的必然推论，而非数据缺失**。

### 6.2 复合往返恒等（NG-9）

复合链 `λ → κ_bridge = 1/(4πλ) → κ_cand = κ_bridge → c = λ/r → λ′ = c·r` 实跑：k ∈ {1e-6, 1e-3, 1, 1e3, 1e6}，每例 5 轮，每轮相对偏差 ≤ **2.220e-16**；20 组独立重算 max |λ′/λ − 1| = 2.220e-16（机器精度）。**复合式反复转换不改变 λ 的自由度，该逃逸通道负结果闭合。**

## 7. 口径拦截、复合不生成标度与判定风险（NG-10 / NG-11 / NG-12）

### 7.1 口径拦截定理（NG-10）

域限定口径 DL(η)（每颗行星半径带 ±η 相对容差）：解析上 span_c(η) ≡ (1+η)²、ε_κ ≡ 0。数值-解析相对偏差 ≤ 4.44e-16（全 8 例）；可行集覆盖率仅 **0.2739%**。

> 任何**仅收缩定义域 / 仅重参数化**（不引入新外部带量纲锚）的口径变换，其数值达标项在【全字段显式化】闸门链下必被 **HG-3′（零残差蕴含冻结同族）** 或 **HG-8（常数比同族）** 拦截。**域限定口径不构成逃逸通道。**

### 7.2 复合换算不生成绝对标度（NG-11）

非线性桥接 κ_bridge = 1/(4πλ)·(1 + β·ln(r/r₀))：往返链偏离精确等于 β·ln(R)（β = 0.1 时为 **0.4625175457795831**），但该偏离对规范缩放 λ → kλ **完全不变**（沿 k 跨度 ≤ 6.66e-16）。⇒ 复合换算只是新增一个同样需要外部定值的参数 β，**不生成绝对标度**。

### 7.3 判定风险（NG-12，非正向结论）

六闸门累积显式化填充序列实测显示：`gate_state` **非单调**，且「通过」只能靠「少给字段」获得（补上指称注册表即被 HG-8 拦回）。⇒ **凡未做全字段显式化的通过判定，一律降级为口径条件通过，禁止据此判定打通。**

最小全显式字段集：`cand_scale, target_scale, hg3_implied_scope, referent_registry, cand_series, dim_semantics`。

## 8. 外部锚量纲门审计：λ 通道在量纲上不存在

对「外部带量纲锚」（PRED-A1）通道做量纲自洽性门审计，结论如下：

### 8.1 WGE 的 λ 与星系反演式的 λ 不是同一个东西

| 项 | 定义 | 量纲 (L, M, T) | 性质 |
|---|---|---|---|
| λ_WGE | 引力衰减长度（扫描网格 1e20 – 1e21 m） | (1, 0, 0) = 长度 | 一万光年量级 |
| λ_gal | λ = V⁴/(G·M·a0) | (0, 0, 0) = 无量纲 | MOND 偏差比，恒 ≈ 1 |

### 8.2 「相差约 20 个数量级」是单位记账伪差

log10(1e20) = 20.0，与历史报告值逐位吻合 ⟹ 该落差恰是「把无量纲数当成 1e20 m」的量纲记账错位，**不是物理落差**。

### 8.3 唯一量纲自洽的 λ↔质量桥数值上不可达

康普顿桥 m_eff = ħ/(cλ)：

| 输入 | 输出 | 问题 |
|---|---|---|
| λ = 1e20 m | m_eff = 3.518e-63 kg | 比电子轻 32 个数量级，无对应可测粒子 |
| m = m_e（实测） | λ = 3.862e-13 m | 与 1e20 m 相差 **32.41 个数量级** |

### 8.4 净判定

| 通道 | 判定 | 否决层级 |
|---|---|---|
| 时间标度 T | 封闭 | 幂次（w = 0，精度无关） |
| 质量标度 M | 封闭 | 幂次（w = 0） |
| 组合量 G | 封闭 | 幂次（w = 0） |
| λ_gal = V⁴/(GMa0) | 否决 | 量纲（无量纲 ≡ 1，非长度 λ） |
| λ_K4 = ħ/(mc) | 否决 | 数值（32.4 个数量级不可达） |

> **净判定**：在现行表述（λ 为长度 + 康普顿口径桥）下，**不存在量纲自洽且数值可达的外部观测量可承载 λ 的绝对标度**。PRED-A1 的「合格外部锚 = 0」**不是数据收集不足，而是表述层缺口**。
>
> **范围声明**：本判定仅覆盖项目现行公式集；新增一个带量纲的耦合即可另开通道。故这不是对整个框架的最终否决，而是对「用现成天文数据补锚」这条路的否决。

## 13. 结论

1. **框架本体可算、可复现**：WGE 的几何—涨落层构成闭环，判据 β ∈ (β_B, β_A) 及其数值（β_B 五点、α_max = 0.452036、稳定占比 0.095125（口径 C））经独立重跑逐位一致。
2. **互斥性是硬结论**：在 λ 常数前提下，(1+ε)·span ≡ R 使 κ-恒等与 c-常数不可两全；紧界 span ≥ max{1, R(1−ε)/(1+ε)} 可达且 0 违例；现行判据自身不相容。
3. **不可能性有精确阈值**：闭合存在的充要条件为 tol ≥ tol* = (R−1)/(R+1) = 0.9805864205272267；严格口径下要求域宽 ≤ 2.22e-16，而实际 R = 102.0207，差 102.02 倍。
4. **放宽前提可解但退化不可消除**：λ 场变量路线精确满足条件（ε = 0、span = 1），但 λ 退出常数集、标度不可内生、判据被架空——属退化迁移，非打通。
5. **不可闭合可被结构性归因**：规范权重代数表明项目内观测量分为 w = 0（判别力恒 0，48 项）与 w ≠ 0（需外部定值，294 项）两类；复合转换、口径收缩、非线性桥接均不生成绝对标度。
